# Master-s-thesis
This repository contains the MATLAB codes I wrote to extract and analyse experimental PTV data on a turbulent pipe flow fir my master's thesis work. 
densityViscosityWaterGlycerolSolution.m is the function used to determine the physical properties of the fluid inside the pipe (water-glycerol mixture) starting from the measured properties (density, temperature, refractive index).
main.m is the main script used to extract the results (contained in the camp1000 folder) and extract the quantities of interest. Initial analyses and plots are also performed in this file, where an initial approach regarding the methodology of extraction of the data is done.
